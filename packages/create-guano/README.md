# create-guano

Scaffold a new [Guano](https://www.npmjs.com/package/guano) site project.

```sh
npm create guano my-site
cd my-site && npm install && npm run dev
```

Generates a project directory with `guano` as a dependency, `dev`/`start`/`build`
scripts, a `.env.example`, and a `.gitignore`. Open
`http://localhost:4174/admin` after `npm run dev`.
